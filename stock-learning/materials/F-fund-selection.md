# F - 基金筛选与体检框架（对标 L1-L6）

基金不是公司，没有三张表可抠。选基只看四件事：**业绩是否经风险调整后仍好、持仓是否漂移、费率与人是否值得付、与你现有组合是否互补**。本框架固定为 **F1-F4** 四维度，与 `L1-L6` 选股框架并列，专用于指数与主动基金的准入、持有与卖出判断。

> 中澳通用：澳洲大概率买 **ETF**（`VAS / IVV` 等，`Stake` 交易，`AUD` 计价，`CHESS` 持有），国内大概率在 **支付宝** 买（`景顺 001422` 等 `固收+` / 主动权益，`RMB` 计价，`天天基金/晨星` 数据）。阈值同时给出中澳口径，取其一比即可。
>
> 轻量定位：`F1-F4` 合计信息量约 `L1-L6` 的 40-50%。指数基金（VAS/IVV）仅需 `F1+F3` 即可定性，主动基金（景顺）跑满四维。

---

## F1 - 业绩（风险调整后回报）

**目的：** 回答“这只基过去赚钱是靠实力还是靠运气/靠承担更大风险”。不看单期收益，看**经风险调整后**的持续性。

### 核心指标

| 指标 | 定义 | 好/坏阈值 | 数据来源 | 看多久 |
|---|---|---|---|---|
| 年化回报（1/3/5年） | 区间复权净值年化 | 跑赢业绩基准 `+2%` 以上为好 | 天天基金/晨星 | 1/3/5年都要看 |
| 最大回撤 / 修复时长 | 峰值到谷值最大跌幅 / 回到峰值月数 | 主动固收+：`≤ -3%` 优秀，`-5%` 警戒；权益类：`≤ -15%` 可接受 | 同上 | 近3年 |
| 年化波动率 | 日收益标准差年化 | 越低越好，同类分位 `前1/3` 为好 | 同上 | 近3年 |
| 夏普比率 | `(年化 - 无风险) / 波动` | `>1.0` 优秀，`0.8-1.0` 良好，`<0.5` 差 | 晨星（3年） | 近3年 |
| 索提诺 / 卡玛 | 只惩罚下行波动 / 年化/最大回撤 | 辅助夏普，索提诺 `>1.2` 好，卡玛 `>1.0` 好 | 晨星/且慢 | 近3年 |
| 月胜率 / 连续跑赢月数 | 跑赢基准的月份占比 | `>55%` 好，`>60%` 优秀 | 自算 | 近3年 |

**阈值示例（以你的持仓为锚）：**
- 景顺 001422：近1年 `+10.8%` / 最大回撤约 `-3%`（2021-12至2022-04）/ 夏普近3年约 `1.1` → `F1` 优秀
- VAS：近3年年化 `+10.5%` / 最大回撤 `-16%`（2022）/ 夏普 `~0.6` → 指数正常，不以夏普论优劣
- IVV(AUD)：近3年年化 `+19%` / 最大回撤 `-16%` / 夏普 `~0.9` → 美股Beta驱动，回撤修复 `2.5年`

**使用规则：**
- 单看1年夏普无意义，必须 `3年` 且与**同类中位数**比（固收+跟固收+比，不跟沪深300比）。
- 最大回撤比夏普更重要——你家庭计划的现金流要求（装修/旅游 `A$6,000/月`）决定回撤容忍度，`景顺 -3%` 能扛，`沪深300 -40%` 不能扛。

## F2 - 持仓（股债比与集中度）

**目的：** 回答“它有没有漂移、是不是你以为的那只基”。基金季报持仓是唯一真相。

### 核心指标

| 指标 | 定义 | 好/坏阈值 | 看多久 |
|---|---|---|---|
| 股/债/现金占比 | 季报资产配置 | 固收+：股 `0-20%` / 债 `70-90%` 为稳健，股 `>30%` 为漂移 | 近4季 |
| 前十集中度 | 前十持仓占净资产 | 主动权益 `>50%` 为集中，`<30%` 为分散；固收+看前五债券 `>20%` 为集中 | 近4季 |
| 行业/久期 | 股票行业分布 / 债券久期 | 行业单一 `>40%` 为集中风险，久期 `>5年` 对利率敏感 | 近2季 |
| 换手率 | 年换手 `= 买入+卖出 / 均值` | 固收+ `<200%` 稳健，`>400%` 为交易型 | 年 |
| 持仓稳定性 | 连续季报重仓股重合度 | 重合 `>70%` 为稳定，`<50%` 为漂移 | 近4季 |

**阈值示例：**
- 景顺 001422：股约 `10-15%` / 债 `80%+` / 前十约 `25%` / 换手约 `150%` → 稳定固收+，未漂移
- VAS：`金融 27.7% + 材料 17.9%` 集中，前十 `~47%`（CBA 10.5%/BHP 7.7%）→ 指数必然集中，接受即可
- IVV：科技 `~30%`（英伟达/微软/苹果前三大 `~15%`）→ 美股集中是特性，不是风险

**使用规则：**
- 季报后必看 `F2`，连续两季股占比 `+5%` 或前十更换 `>50%` 即漂移预警。
- 指数基金（VAS/IVV）不考核漂移，只看**跟踪误差**（年 `<0.3%` 优秀）。

## F3 - 费率与人（成本与经理）

**目的：** 回答“值不值得付这个费、这个人能不能持续”。费率是唯一确定的负收益。

### 核心指标

| 指标 | 定义 | 好/坏阈值 |
|---|---|---|
| 管理费 | 年费率 | 指数 `<0.15%` 优秀（VAS 0.07%/IVV 0.04%），主动 `<1.0%` 可接受，`>1.5%` 贵 |
| 申购/赎回费 | 买入卖出成本 | 线上申购 `0.10%`（1折）为常态，`>0.6%` 贵；持有 `<7天` 赎回 `1.5%` 惩罚 |
| 规模 | 净资产 | 固收+ `<2亿` 清盘风险，`>10亿` 稳定；`>100亿` 可能钝化 |
| 经理任职年限 | 现任经理管理本基时长 | `<2年` 不稳定，`>5年` 可信，`>8年` 优秀 |
| 经理年化超额 | 相对基准年化超额 | `>2%` 优秀，`0-2%` 良好，`<0` 差（看3年） |
| 机构持有占比 | 机构持有比例 | `>30%` 为机构认可，`<5%` 为散户基 |

**阈值示例：**
- 景顺 001422：管理费 `0.60%`（固收+偏低）/ 申购 `0.10%` / 规模 `13.62亿` / 经理陈莹 `2015-06` 任职 `>8年` / 近3年超额 `约+3%` → `F3` 优秀
- VAS：`0.07%` / 规模 `A$250亿` → 指数天花板
- IVV：`0.04%` / 规模 `A$140亿` → 同上

**使用规则：**
- 管理费每高 `0.5%`，10年复利少 `~5%` 总收益，指数必选最低费率。
- 经理变更即重审 `F3`，任职 `<2年` 的新基不进 `其他基金 ≤50%` 池。

## F4 - 适配（与你组合的相关性）

**目的：** 回答“它跟你已有的 VAS/IVV/现金是否互补，还是重复”。单只基再好，与组合同涨同跌就是累赘。

### 核心指标

| 指标 | 定义 | 好/坏阈值 |
|---|---|---|
| 与 VAS/IVV 相关系数 | 日收益 `3年` 相关系数 | `<0.6` 为分散好，`>0.85` 为重复 |
| 回撤同期表现 | VAS 回撤 `-16%` 时它的回撤 | 跌幅 `<1/2 VAS` 为对冲好，`> VAS` 为放大 |
| 收益来源 | 股/债/汇率驱动 | 与现有组合驱动不同为好（景顺靠债 vs VAS靠银行） |
| 汇率暴露 | 美元/澳元计价 | IVV 为美元资产，AUD升值会侵蚀 `5-8%` /年 |

**阈值示例：**
- 景顺 vs VAS：相关系数约 `0.2`（债 vs 股）→ 互补，`2022 VAS -16%` 时景顺仅 `-3%` → 完美对冲
- IVV vs VAS：相关系数约 `0.7`（美股 vs 澳股）→ 中度相关，分散有限但提供科技敞口
- 固收+新基 vs 景顺：若相关系数 `>0.8` 且持仓重合 `>50%` → 重复，不进池

**使用规则：**
- 家庭组合目标：`VAS 50% + IVV 30% + 景顺 10% + 现金 10%` 时，整体相关系数应 `<0.7`，最大回撤应 `< -10%`。
- 新基进入 `其他基金 ≤50%` 池前必跑 `F4`，相关系数 `>0.85` 直接否决。

## 中澳平台差异速查（阈值已兼容）

| 维度 | 澳洲 ETF（Stake, AUD） | 国内支付宝基金（RMB） |
|---|---|---|
| 数据源 | `Morningstar AU / ASX 公告 / Stake` | `天天基金 / 晨星中国 / 且慢` |
| 费率锚 | `VAS 0.07% / IVV 0.04%` 为天花板 | `景顺 0.60%` 为固收+低位，主动权益 `1.20%` 常见 |
| 规模锚 | `VAS A$250亿 / IVV A$140亿` | `景顺 13.6亿` 为 mini 稳定线，`<2亿` 清盘风险 |
| 分红 | `franking credits` 可抵税 | 无此机制，看现金分红率 |
| 汇率 | `IVV` 为美元资产，`AUD/USD` 影响 `5-8%` /年 | `RMB` 计价无此项 |

> 阈值取宽松者：如 `管理费` 同时满足 `指数 <0.15%`（中澳通用）即过；`规模` 按所在市场锚判断即可。

## 评分与应用

**打分：** `F1 40分 + F2 20分 + F3 20分 + F4 20分 = 100分`，`≥75` 可入池，`≥85` 优秀。

**流程：**
- 指数（VAS/IVV）：年审一次，`F1+F3` 即可，`F2/F4` 年更。
- 主动（景顺及新基）：半年审一次，`F1-F4` 全量，季报后加审 `F2`。
- 触发重审：`F1` 最大回撤破阈值 / `F2` 连续两季漂移 / `F3` 经理变更 / `F4` 相关系数 `>0.85`。

**卖出：** `F1` 夏普 `<0.5` 连续1年 / `F2` 股占比漂移 `+10%` / `F3` 管理费上调 / `F4` 与 VAS 相关系数 `>0.85` 且收益无超额。
