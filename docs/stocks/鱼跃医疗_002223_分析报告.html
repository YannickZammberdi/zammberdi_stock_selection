同时必须说明本版的两处"口径修正"，否则读者会误判为旧版数据错误：
  • 口径修正一 — 旧版年度数据准确无误，错在漏掉了最新一期。旧版写的 FY2025 年报披露日 2026-04-25 是正确的，ROE 22.45% → 14.82% → 11.42% 也精确对应 FY2023/FY2024/FY2025 加权平均 ROE（2025 年报摘要原表），截至今天仍是最新完整年度口径。但 2026 年半年报已于 2026-08-21 晚间 / 08-22 披露，旧报告发布仅 3 天就漏掉了最新报告，导致完全遗漏了营收转负、利润降幅扩大至 −30%、政府补助骤降 2.2 亿、呼吸板块 −13.3%这一组决定投资判断的最新信号。本版的核心增量信息全部来自 2026H1。
  • 口径修正二 — "货币资金从 66.19 亿暴跌到 5.79 亿"是假象，根因是科目重分类。公司自 2025 年下半年起将大额定期存款/结构性存款从"货币资金"重分类至"其他流动资产"与"其他非流动资产"，现金类资产总额并未减少。详见 L1 资产负债表。若只列"货币资金 13.79 亿"，会严重误导为"现金枯竭"。

2026H1 是决定性拐点信号——营收 −1.92%（由 FY2025 的 +5.14% 转负）、归母 −29.92%（降幅较 FY2025 的 −17.94% 显著扩大）、政府补助净减超 2.2 亿、最大板块呼吸治疗 −13.33%。三个维度同时失速，且不是一次性扰动：毛利率三年稳定在 50% 上下，说明产品竞争力未受损，问题出在"收入停滞 + 政府补助退坡 + 费用前置投放"三件事上。

核心优势：
① 现金创造力是全市场最强项之一：TTM CFO/归母净利 = 1.35，2026H1 单期 1.40——归母利润腰斩式下滑（−29.92%）的同时经营现金流仍逆势 +1.31%。利润的"含金量"没有问题，问题只在"利润的规模"

③ 结论：TTM 口径 ROE ≈ 8.4%（扣非 ≈ 7.65%）是"当前真实盈利能力"的最佳代表，明显低于旧报告引用的 11.42%。本报告所有 ROE 评分、估值锚点均以此为准。

5.3 赚钱模式判断

赚钱模式：均衡型（偏"高利润型"遗产），当前已滑向"均衡型"的中段。
TTM 三项因子：净利率 14.27%、周转率 0.483、权益乘数 1.241。
· 不是高周转型：总资产周转率 0.483 次/年在 800 亿营收体量下（行业领先）但并非主要驱动，且三年基本持平（0.513→0.479→0.5014）；
· 不是高杠杆型：权益乘数 1.241，资产负债率仅 20.42%，杠杆已无空间可用；
· 曾是高利润型：FY2023 净利率 30.05%，但 TTM 已降至 14.27%，腰斩。
→ 均衡型对应杜邦质量 3/5 分，三项均无突出项，且 ROE 下滑全部来自净利率。

5.4 核心结论

杜邦核心结论 — ROE 下滑 100% 来自"净利率"这一个因子，周转率与杠杆反而是正贡献。

① 因子贡献拆解（FY2023 → TTM）：
· 净利率 30.05% → 14.27%（降 52.5%）→ 贡献了几乎全部 ROE 降幅
· 总资产周转率 0.513 → 0.483（降 5.8%）→ 基本持平，非问题所在
· 权益乘数 1.437 → 1.241（降 13.6%）→ 名义上是"负贡献"，但性质完全不同：这不是公司主动去杠杆，而是巨额分红（近三年 26.06 亿）+ 现金堆积导致的被动"权益增厚"。分子（资产）被闲置现金撑大，分母（权益）被留存利润与分红同时推高。

② 净利率下滑的三层可量化拆解：
· 毛利率基本稳定 → 不是产品竞争力问题：50.14%(FY2024) → 50.60%(FY2025) → 49.80%(2026H1)，三年几乎持平
· 政府补助退坡 → 政策性收益消失：FY2024 2.76 亿 + FY2025 3.11 亿 → 2026H1 仅 0.60 亿，净减 2.25 亿；公司自述"不具有可持续性"
· 费用率上行 → 前置投入尚未兑现：销售费用率 17.99%(FY2024) → 22.16%(FY2025) → 18.26%(2026H1)；期间费用率 26.24%(2025H1) → 29.15%(2026H1，+2.91pct)

③ 趋势是否健康：不健康，但可解释、可跟踪。
这是"利润率问题"，不是"运营效率问题"，也不是"杠杆问题"。好消息是三个恶化因子中有两个（费用率、补助退坡）具有阶段性——只要收入端恢复增长，费用率会自然摊薄，补助缺口不会进一步扩大（基数已低）；坏消息是唯一真正的长期变量——收入端能否重回增长——目前尚未看到证据（营收 −1.92%、呼吸板块 −13.33%）。
资产回报效率参考：TTM ROA = 14.27% × 0.483 = 6.89%，即每 1 元总资产产生约 0.069 元归母净利。作为对照：FY2023 为 15.42%、FY2024 为 11.43%、FY2025 为 9.34% —— 去掉杠杆后的基础回报同样在持续下滑，说明问题无法通过"加杠杆"或"提周转"掩盖。

六、行业分类（L5框架）

6.1 行业类型判断

行业类型：非周期股（医疗器械 — 家用医疗器械，细分偏"成长型 + 防御型混合"）。采用非周期股评分体系，与总结论一致。

依据：家用医疗器械需求由老龄化、慢病管理、消费升级三大长期驱动因素支撑，与商品周期（供需错配驱动利润）弱相关。按 `industry-classification.md` 的周期/非周期二分法，"医疗器械"明确归入非周期股清单（需求稳定、利润可预测）→ 必须用非周期股评分体系，L3 用 PE Band（已执行，未用 PB Band）。

细分定性：细分看，"院外家庭医疗（OOH）"兼具防御属性（慢病用药、监测刚需）与成长属性（消费升级带来的新品类渗透），但当前阶段公司自身处在"存量竞争 + 赛道去库存"周期位置（见 6.3），成长属性在 2026H1 已被 −1.92% 的营收增速证伪。

公司愿景：全球院外（OOH）市场前三的领先医疗器械集团。

6.5 估值方法匹配

估值方法：非周期防御型/消费型器械 → 首选 PE，辅助指标为股息率与 PB。匹配度：部分匹配，但当前倍数处历史偏贵区间。

按 L5 框架的行业—估值对应表：
· 防御型（公用事业）→ PE / 股息率，辅助 EV/EBITDA，看现金流稳定性
· 消费（白酒/家电）→ PE，辅助毛利率 / ROE，看品牌力
鱼跃兼具两者属性（家用慢病刚需 + 消费品牌），PE 为主、股息率为辅是正确选择，本报告已按 PE Band（而非 PB Band）展开。现金流稳定性指标 PCF(TTM) ≈ 17.0 也支持这一选择。

当前市场使用 PE 的做法本身正确，问题在倍数：PE(TTM) 23.44 已高于历史 80% 分位（20.94）；PE(2026E) 16.6–16.7x 在合理区间内。PEG 角度：一致预期 2026E 归母 +4.69%、2027E +15.9% → 以 2027E 增速 15.9% 计，PEG = 16.7 / 15.9 ≈ 1.05（若用 2026E 增速 4.69% 计则 PEG ≈ 3.56，严重不达标）。PEG 的结论完全取决于用哪一年增速 —— 这再次指向"盈利路径无共识"这一核心问题。

七、综合实战（L6框架）

7.1 六步法总结

Step 1 - 行业定位：非周期股（医疗器械—家用器械，细分偏成长+防御），采用非周期股评分体系 + PE Band。行业分散、多品类领先者（电子血压计国内第一、制氧机国内龙头、AED 国内前三、CGM 约 7% 份额）。壁垒类型：品牌（强）、牌照/注册证（强）、渠道（强，覆盖 130+ 国家、30 万家医疗机构）、规模（中强）、技术（中）。当前周期位置：行业整体"去库存、业绩承压"底部区间，院端内卷促使迈瑞/联影/威高集体下切家用赛道 → 竞争强度将上升。

Step 2 - 财务体检：TTM 归母 ROE 8.44%（扣非 7.65%），显著低于 FY2025 的 11.42%。杜邦类型为均衡型（3/5 分）——净利率 14.27%、周转 0.483、乘数 1.241，三项无突出项。ROE 下滑 100% 来自净利率，周转与杠杆非问题所在。CFO 质量为最强项：TTM CFO/归母净利 1.35（2026H1 单期 1.40），利润 −29.92% 下现金流仍 +1.31%。资产负债表零瑕疵：资产负债率 20.42%、零有息借款、现金类资产约 79.6 亿占总资产 47%。

Step 3 - 估值判断：PE(TTM) 23.44 vs 合理区间 10–18x（ROE 约 11% 口径）→ 偏高约 30%，且高于历史 80% 分位 20.94（理杏仁 2026-08-14 标注分位 71.35% 但区间未标注）。PE(2026E) 16.6–16.7x 在区间内。PB ≈ 1.94（申万均值 2.68）、股息率 3.87%（申万均值 1.31%）、PS(TTM) 3.28、PCF(TTM) 17.0。核心风险：同一天国联民生给出 12.45 亿与 15.26 亿两个相差 22% 的 2026E 预测（PE 20.7x vs 16.7x），前瞻 PE 极不稳定；机构一致预期跨度从 12.45 亿到 17.30 亿（近 40% 区间）。

Step 4 - 风险排查：🔴 上海中优被暂停军队采购资格（2026-08-17，四个月内两次公示，正落在 10.77 亿商誉对应资产上）；🔴 新增被执行人 1,312.45 万元（丹阳市人民法院，案由未公开）；🔴 应收账款 +77.67% vs 营收 −1.92%，周转率连续三期下滑；🔴 呼吸板块 −13.33%；🔴 政府补助净减超 2.25 亿且"不具有可持续性"；🔴 FY2025 Q4 单季扣非为负。

Step 5 - 结论：好公司？资产负债表与现金流是的（零负债、现金占总资产 47%、CFO/净利 1.40、分红率 67.65%），盈利能力的成长性目前不是（TTM ROE 8.44%、营收转负）。价格合理？TTM 口径偏高约 30%，2026E 口径在合理区间内，估值结论高度依赖尚待验证的盈利修复假设。综合评分 65/100 → 一般关注（verdict-caution）。

Step 6 - 跟踪：① 2026 三季报（第三方推算约 10-24，官方预约日数据待补充）：扣非归母单季是否回正、呼吸板块是否止跌、销售费用率是否见顶；② 政府补助后续是否还有"退坡二次冲击"；③ 上海中优军队采购资格的后续处置与是否触发商誉减值测试；④ 应收账款余额与周转率能否止跌；⑤ 陆股通持股比例（3.03%→3.76%→2.69%）是否继续下降、股东户数（82,327 户）是否继续激增；⑥ 2026-11-15 限售股解禁 5.83% 总股本的承接情况。卖出信号：单季扣非再度为负 + 呼吸板块双位数下滑延续 + 应收账款继续跑赢营收 → 2026E 一致预期 15.51 亿下修，PE(TTM) 23.44 转为实质高估。

7.3 风险评估

a. 三个陷阱排查

☐ 低 PE + 低增长 + 高负债 = 价值陷阱 → 未命中（PE(TTM) 23.44 不低；资产负债率 20.42%、零有息负债，不构成高负债陷阱）
