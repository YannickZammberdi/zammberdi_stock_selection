5.5 核心结论

杜邦结论：ROE 提升的路径是"利润率（经营性）× 周转率"，杠杆全程缺席；但 2026H1 的利润率抬升必须打折看待。
① 结构性判断：权益乘数常年 1.06–1.09，说明这家公司的 ROE 完全由「净利率 × 周转率」驱动，杠杆贡献接近于零。这意味着 ROE 的可持续性完全取决于经营，不需要担心债务扩张带来的脆弱性 —— 评分为"高利润型"满分 5/5。
② 趋势判断：FY2025 ROE 提升 2.23pct 中，净利率贡献 −0.19pct（拖累）、周转率贡献 +0.042 次（正向）、乘数贡献 +0.013（微正）—— 周转率是唯一正向驱动，说明 FY2025 的 ROE 改善是真实的经营效率提升，而非财务技巧。
③ ⚠️ 2026H1 必须打折：本期 ROE 年化提升至 25.1%（杜邦）/24.7%（官方加权），表面看净利率跳升 10.9pct 是最大功臣，但其中 4.94pct 来自财务费用率下降（即利息收入 7,566 万元、同比 +646%，财务费用 −7,432 万元、占归母净利 9.4%）——这是净现金 53.7 亿元在利率环境下产生的被动收益，不是经营改善，不可外推至 FY2027。剔除后经营性净利率约 51%，与 FY2025 的 50.67% 基本持平，扣非归母净利率 55.83% 是更合适的观察口径。
④ 交叉验证：CFO/净利从 FY2023 的 1.181 → FY2024 的 1.079 → FY2025 的 0.993 → 2026H1 单期 0.644（TTM 0.838），连续三期下行，与"利润含金量下降"一致。因此本期真实的经营性 ROE 提升幅度，应以 23.0%（扣非年化）而非 25.4% 作为更审慎的参考。
⑤ 前瞻判断：只要"平面"业务止血（增速回到 10% 以上）、"其他"业务的高增长延续、且周转率继续改善，去杠杆 ROA 有望向 25% 以上迈进；反之若毛利率跌破 70% 且营运资本占用持续，经营性 ROE 将在 20% 附近见顶。

6.5 估值方法匹配

估值方法：成长型（科技）首选 PS / PEG，辅助 PE —— 当前市场使用的 PE + PS 组合与行业类型基本匹配，但存在两点需要修正。
① 匹配之处：市场同时给出 PE(TTM) 29.11x、PE(2026E) 26.5x、PS(TTM) 15.47x、PEG（PE 26.5 ÷ 净利增速 24.29% ≈ 1.09，落在健康区间）—— 这正是成长型科技公司的标准定价方式，符合 industry-classification.md 中"成长型首选 PS/PEG，辅助 PE（盈利后）看营收增速"的规则。PEG < 1.5 的"好价格"条件满足。
② 需修正之一：不能只看 PE，需做"利息收入剥离"。当前 PE(TTM) 29.11x 的分母含 9.4% 占比的财务费用贡献，若按经营性利润（剔除利息收入后净利率约 51%）重算，经营性 PE 约 35x，已进入合理区间上沿之外 —— 这正是 L3/L4 反复强调的问题。
③ 需修正之二：PB 需要结合 ROE 消化能力看。PB 5.74x 对应 ROE 年化 24.7%（扣非 23.0%），隐含要求是"ROE 至少维持 20%+ 且可长久"。当前 PB 高于 FY2024 末 3.85x、FY2025 末 4.87x，需要 FY2027–FY2028 的 ROE 兑现来消化，而 ROE 中 4.94pct 来自不可外推的利息收入，这削弱了 PB 的安全边际。
④ 辅助指标建议：因毛利率三连降 + 结构切换，建议同时跟踪 "软件收入占比"与"软件毛利率"（当前平面 79.69%、管材 82.30%），这是判断 PE 是否应当下修的最直接信号；另可关注 EV/EBITDA 口径（EV 313 亿元已剔除 53.7 亿元净现金，更能反映经营价值），但 EBITDA 数据未获取到 → 数据待补充。

7.1 六步法总结

Step 1 - 行业定位：非周期成长型（工业软件）。中低功率 CR3 > 90%、公司第三方测算约 60% 市占；高功率第三方测算约 40% 且仍"国内第一"（公司口径）。壁垒 = 技术 + 客户切换成本 + 硬件规模效应；牌照/网络效应弱。生命周期成长期后段，渗透率 60%。设备端连续两年负增长（2024 −1.4%、切割成套 −5.1%），公司超额增长靠份额 + 结构升级；船舶（2026H1 民用钢质船产量 +44.4%）是最强顺风下游。

变量一：平面基本盘增速（当前 +4.39%，占收入 58.89%，FY2025 为 +14.94%）—— 最关键变量
乐观：受船舶（2026H1 民用钢质船产量 +44.4%）与钢结构复苏带动，平面增速回到 12% 以上且"其他"维持 50%+ → 2026E 归母 14.7 亿元（EPS 3.63 元）（广发预测）；
中性：平面维持 5%–8%、"其他"维持 55%–65% → 2026E 归母 13.83 亿元（EPS 3.41 元）（12 家一致预期）；
悲观：平面零增长或负增长、"其他"增速回落至 35% 以下，合计增速降至 10% 以内 → 2026E 归母 13.5 亿元（EPS 3.33 元）（华西预测）。
敏感度提示：平面毛利率 79.69% vs "其他" 48.17%，占比互换 1pct → 综合毛利率变动约 0.32pct；若平面占比从 58.89% 降至 52%，综合毛利率将再降约 2.2pct 至 71.7%。

变量二：利息收入可外推性（2026H1 为 7,566 万元、同比 +646%，财务费用 −7,432 万元、占归母净利 9.4%）
乐观：10.7 亿元闲置募资现金管理 + 53.7 亿元净现金维持高息，FY2026 利息收入维持在 1.5 亿元量级 → 对 EPS 贡献约 +0.37 元（未计税）；
中性：利率温和下行 + 部分现金用于新项目（锂电焊接、三维五轴），FY2026 利息收入回落至 1.2–1.3 亿元 → 相对 H1 年化小幅缩水；
悲观：利率快速下行或募投资金投入运营，FY2026 利息收入回落至 0.8 亿元以下 → 单此一项将使归母净利减少约 0.7 亿元（约 5%），且净利率从 61.58% 回落至 56% 附近，PE(TTM) 被动升至 32x+。

变量三：营运资本占用与 CFO 修复（2026H1 应收 +32.58%、存货 +30.46%，CFO/净利 0.644）
乐观：2026 年报应收/存货回落、CFO/净利回到 0.95–1.0 → 利润质量分由 10/15 回升至 15/15，估值中枢可上移至 28–30x；
中性：营运资本维持当前水平，TTM CFO/净利 0.83–0.85 → 利润质量分维持 10/15；
悲观：应收/存货继续双位数增长且 CFO 连续两期负增长，TTM CFO/净利跌破 0.7 → 利润质量分降至 5/15，同时触发估值体系下修至 20x 悲观情景（对应股价 66.6 元）。

7.4 前景展望

正向驱动：
1. "其他"业务的结构性高增长（智能焊接 + 精密微加工 + 切割头） — 2026H1 +64.75%、贡献 57.6% 的增量收入；波刺自动化 2024 年收入 4.95 亿元、净利 2.02 亿元（净利率 40.84%），硬软一体使公司从"卖软件"变为"卖整机核心部件"，单机价值量从 1–1.5 万元提升至数万元量级。
2. 船舶与高端钢结构需求 — 2026H1 我国民用钢质船舶产量同比 +44.4%（广东占 36.5%）；2024 年手持订单 20,872 万载重吨（相当于 4.3 年的完工量），是当前对冲设备端下行的最强顺风。
3. 高功率国产替代仍未结束 + 五轴三维新品类 — 高功率份额从约 10%（2021）提升至第三方测算约 40%，剩余 60% 的替代空间；运动控制系统国产占比 60%、智能控制系统渗透率 60%，仍有提升余地；"三维五轴高速柔性制造"研发项目预计总投资 5,500 万元、本期已投入 978 万元。
4. 财务与股东回报的确定性 — 净现金 53.7 亿元、负债率 5.32%、无长期借款；FY2025 分红率 50.20%、2026 中期拟派 29.99%、股息率约 2.0%；募投项目全部结项、节余 4.44 亿元永久补流，资本开支高峰已过，FCF 将持续释放。

负向拖累：
1. 毛利率的结构性、不可逆下行 — 主营口径 80.53% → 77.92% → 73.93%，硬件替代软件（FY2025 硬件销量 +61.81% vs 控制系统 +6.67%）+ 上游电子元器件涨价 + 切割头配比率提升；按当前结构互换速度，中期毛利率仍有 2–3pct 下行空间。
2. 利息收入的不可持续性 — 2026H1 利息收入 7,566 万元（+646%）贡献了净利率跳升的 4.94pct、财务费用 −7,432 万元占归母净利 9.4%；随着利率下行与募投资金投入运营，FY2027 利润增速将受实质拖累，PE(TTM) 会被动走高。
3. 营运资本占用与现金流背离 — 应收 +32.58%、存货 +30.46%，应收周转天数 23.85 → 27.42、存货周转天数 152 → 156 两项同时恶化；CFO −8.84%、CFO/净利 0.644，若 2026 年报未修复将触发利润质量降档。
4. 筹码分散与估值缺乏历史分位支撑 — 股东户数半年 +53.7%（10,812 → 16,612 户）、前十大机构持股比例 −1.69pct、股价在 50 日（99.58 元）/200 日（103.85 元）双均线之下、融资余额 3.14 亿元占流通市值 0.81% 超近一年 50% 分位；股权激励 353.14 万股将在 2026–2029 摊销（总金额待补充）。
5. 海外与新市场的体量尚小 — 其他区域（含海外）约 0.90 亿元、占比仅约 4.2%，境外资产仅 472.2 万元（占总资产 0.07%）；"出海"叙事尚未转化为收入体量。
