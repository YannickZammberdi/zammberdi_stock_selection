利润表解读：这是一份"经营报表与会计报表打架"的分歧年。经营层面是一份非常漂亮的报表：营收（持续经营口径）+12%、经营费用持平、EBITDA +12%、EBIT +15%、核心净利 +15%、DPS +20%，且澳洲经营 EBITDA 利润率从约 62% 抬到 66%（管理层称 "jaws open 4%"）。会计层面是一份难看的报表：1.153 亿减值（去年同期是 1.118 亿转回）把报表 EBITDA 打到 9.44 亿（同比 -9.9%）、报表归母净利打到 5.516 亿（同比 -19%）。减值主要指向 REA India（商誉从 651.3 降到 610.7）与正在关停的 Housing Edge，属于"把已经亏掉的国际业务一次性出清"，与澳洲主业无关。
对本报告的意义：减值是一次性的、不可重复的（商誉已从 651.3 降到 610.7，继续减值空间收窄），因此利润增长维度打 0 分是"会计纪律"的结果而非"基本面恶化"的结论。但反过来也提醒：核心口径 650.5 与报表口径 551.6 相差 9,890 万，这个差额并不全是减值，还包含 REA India 终止经营的重分类与少数股东口径差异，所以两个数字都不能单独拿来做同比。

资产负债表解读：财务结构是这份报告里最没有争议的部分——零有息长期借款、净现金 3.171 亿、负债率 34.6%、有形每股仍为正 A$7.19，在 A 股/港股语境下这属于"教科书级干净"。三个需要盯住的点：

5.2 赚钱模式判断

赚钱模式：典型的高利润型，且是"三高"里最健康的那种高利润型。
ROE 28.6% 的分解：净利率 30.8% × 周转率 0.624 × 权益乘数 1.489。三个因子里，权益乘数只有 1.49——意味着 ROE 几乎全部来自"每元收入赚 0.31 元"和"资产轻到周转 0.62 次"，没有一分钱是杠杆放大的。长期借款从 201.8m 清零至 0、净现金 317.1m 后，这个结构还会更"干净"。
这与高杠杆型（银行、地产开发商）和高周转型（零售、物流）是完全不同的生意：REA 的护城河在于 realestate.com.au 4 倍于 Domain 的流量形成的"流量 → 房源 → 买家 → 更多房源"正循环，广告主（中介）在这个循环里没有替代品。66% 的澳洲经营 EBITDA 利润率不是"涨价涨出来的"，是"结构护城河 + 排他合约"共同锁定的——而排他合约正是 ACCC 现在要拆的那一半。

5.4 核心结论

杜邦结论：REA 的 ROE 完全靠"高净利率"驱动，周转率是短板但被利润率补偿，杠杆贡献接近零。净利率从 FY23 的 31.5% 一路抬到 FY26 的 36.3%（核心口径），靠的是经营费用 +7% 而澳洲营收 +11% 的经营杠杆，以及 FY26 澳洲经营 EBITDA 利润率从约 62% 到 66% 的跳升。趋势健康，但可持续性的答案不在财务里，在监管里——66% 这个数字的定价权基础（全量/多数房源挂牌排他 + 与 listing 层级绑定的赞助条款）已被 ACCC 三年承诺削弱。
另一条线索值得记下：营收增速 FY24 +22.8% → FY25 +15.1% → FY26 +7.2% 的三级台阶，与"全国 Buy 挂牌量已持平"是同一件事的两面。量价拆解显示增长已完全靠价（yield），而价的可持续性现在交到了 ACCC 手里。因此 L6 悲观情景的核心假设不是"澳洲营收下滑"，而是"同样 +12% 的营收只能换回 55-58% 的利润率"。

六、行业分类（L5框架）

6.1 行业类型判断

行业类型：非周期股（成长型，轻度周期），采用非周期股评分体系，与总结论 tab 一致。

判断依据：① 核心收入是广告展示费（yield / impressions，订阅 + 深度 + 赞助合约制），属于按效果付费的信息服务，不是商品价格驱动的价差生意；② REA 已把收入结构转向"产品渗透率 + 每千次展示费率"（Audience Maximiser、Ready25、AI 产品），量的部分被产品渗透替代；③ 澳洲强制养老金（superannuation）制度与人口增长提供长期购房需求底座，住房自有率已高但换房/首购需求持续；④ 需求不由商品价格驱动，因此不适用周期股体系。
为什么标注"轻度周期"：广告展示费的上限最终由房产成交量决定，成交量有地产周期属性；FY26 全国 Buy 挂牌量已持平，正是这一点的直接体现。这不改变"非周期"的分类，但要求在敏感性分析中给周期变量留权重（见 L6 §7.3d）。
为何不用周期股体系：周期股体系的核心是"穿越周期的生存能力 + 周期位置 + 成本优势 + PB 分位"，而 REA 长期借款为 0、净现金 3.171 亿、ROE 连续五年 28-34%，不存在生存问题；周期位置对一门广告平台也不构成 PB 择时依据。故按混合判断取非周期股体系 + PE Band。

6.3 生命周期与周期位置

生命周期：成熟期（主业）+ 成长期（增量业务）的双层结构。澳洲房产中介广告的渗透率已接近天花板（FY26 经营费用持平而 EBITDA +12%，说明已进入收割期）；但金融服务（+11%）、商业与新房（+9%）、AI 产品线仍在成长期，是 FY27-28 增长的主要来源。投资策略重点应放在"成熟主业的现金流"能否持续喂养成长期业务，而非主业本身的量增。

周期位置（本框架的"轻度周期"附注，非周期股体系评分项）：澳洲地产成交周期处于温和走平 / 后周期早段——全国 Buy 挂牌量已持平，增长完全靠 yield 与产品渗透。这既意味着下行缓冲好于纯周期股（广告位不会被立刻撤掉，合约有延续性），也意味着没有量的弹性可用，一旦费率端被 ACCC 压制，利润率的下行没有对冲工具。这是本报告全部风险的核心来源。

6.5 估值方法匹配

估值方法：平台型成长股 → 首选 PE（辅以 PS / PEG），并加 EV/EBITDA 与 FCF 收益率作为交叉验证。当前市场用 PE 为主（报表 37.5x / 核心 31.8x / 前瞻 27.19x），方法上匹配。

但有一处必须调整：FY26 的报表 EPS（4.18）被 1.153 亿减值污染，与核心 EPS（4.935）差 18%，直接用报表 PE 会系统性高估估值水平。因此本报告的处理是：打分用报表口径（保守、可审计），定价用核心口径（反映可持续盈利），两者并列披露。

对比参照：同属信息平台的 Zillow 更适合用 PS 观察（因其盈利尚未正常化），而 REA 因为 EBITDA 利润率已达 60.7%、FCF 利润率 38.7%，用 PE + FCF 收益率（当前 3.73%）比单用 PS 更能反映真实性价比——11.4x PS 看似贵，但配 60.7% 的利润率就等于约 18.8x EV/Sales×利润的性价比，落在合理区间内。

以上为本报告基于 FY26 静态营收的敏感性测算，非公司指引。
变量 2：全国 Buy 挂牌量（FY26 已持平）与 Memory（求购登记）转化率
　乐观：成交量回升带动展示量，Buy 挂牌量同比转正 +3%~5% → 与 yield 增长叠加，澳洲住宅营收可达 +15%
　中性：挂牌量持平（0%），增长完全由 yield 贡献（+8%~10%）→ 澳洲住宅营收 +8%~10%
　悲观：挂牌量同比 -5%（信贷收紧或利率路径上行的滞后效应）→ 展示量与费率同时受压，澳洲住宅营收降至 0%~3%，利润率与营收双杀
　Memory 与 listing 的转化率具体数值数据待补充，为 FY27 最需补齐的领先指标。
变量 3：减值与商誉（商誉 610.7m + 其他无形 347.4m = 958.1m，占总资产 32.9%）
　乐观：印度资产按计划出售给 Aurum PropTech（持股升至 24.9%，需 Aurum 股东批准，预计 FY27 Q1 完成），FY27 无新增减值 → 报表 EPS 与核心 EPS 重新合拢
　中性：印度出售延后或折价，FY27 继续计提 0.5-1.0 亿减值 → 报表净利维持负增长或持平，报表 PE 被动抬高
　悲观：FY27 再计提 1.5 亿以上减值（澳洲主业 goodwill impairment 测试触发 或 Distilled 投资减值）→ 报表净利再次大幅下滑，PB 10.8x 的估值支撑会被质疑

7.4 前景展望

7.4a 未来 1-3 年核心驱动

正向驱动：
1. 经营杠杆仍有空间 — FY26 经营费用持平（704.9 vs 703.6）而核心 EBITDA +12%，澳洲经营 EBITDA 利润率 66%。即使增速回落到个位数，费用端的刚性较低仍可维持利润率（历史上 FY22 57.4% → FY26 60.7% 四年持续抬升）
2. 金融服务与数据业务继续高增 — 金融服务 +11%（按揭结算量 + PropTrack 数据合约）；商业与新房 +9% 仍有渗透空间；Planitar（iGUIDE 3D，2025-10-01 并表，贡献营收 18m）打开商业地产可视化；金融服务占比仅 6.4%，每提升 1pp 都是增量
3. 现金回报持续加码 — 派息率 60%、DPS +20%、回购同比 +871%（FY26 已花 5.685 亿），FCF 7.651 亿持续为正；2026-10 Investor Day 可能给出新的资本回报框架
4. 国际资产出清 — Housing.com 出售给 Aurum PropTech（持股升至 24.9%）完成后，拖累集团增速的 -38% 国际板块（EBITDA -37m）将大幅收缩，集团口径增速会更"干净"

负向拖累：
1. ACCC 三年承诺压制 yield 增速 — 禁止全量/多数房源挂牌排他 + 禁止与 listing 层级绑定的赞助条款 + 允许至少 25% 合资格房源降级，直接削弱"不升层就没曝光"这一变现机制；24 个月后需重新接触意味着前两年是约束期
2. 量端已无弹性 — 全国 Buy 挂牌量持平，增长只能来自价（费率）+ 产品渗透率，而价端正被监管收紧，形成"上不着天、下没有底"的夹击
3. 资本配置三线并进 + 减值余波 — €2.48 亿买入 Distilled 35%（非控股、不并表）、Planitar + Simplicity 已付现 0.901 亿、印度出售待批；商誉与无形 958.1m 的减值压力在 FY27-28 未解除（FY27 Distilled 与印度均可能触发重估）
4. 成本端新变量 — 美国 surcharging 禁令导致 REA 对商户加收供应商手续费（2026-10 上旬起），FY26 成本端已有 Audience Maximiser COGS、Ready25 客户活动、澳网赞助（上年无）、AI 技术投入四项上行，FY27 需确认费用纪律能否维持
