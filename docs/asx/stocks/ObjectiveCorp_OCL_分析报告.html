本报告的机械评分给出 91 分「品质优秀」（上一版 94 分），而股价距 52 周高点 已 -71.3%（19.16 → 5.79），财报当日单日暴跌 20.11%（7.46 → 5.96），市值一年内从约 18.8 亿缩水至 5.54 亿（-70.6%）。这个反差不是评分体系算错了，而是评分体系完全基于 FY2026 已经实现的向后看财务数据，而公司最重要的两项前瞻指标正在恶化：① ARR -2%（调整后口径 -5%）——SaaS 公司最核心的领先指标转负；② FY27 Adjusted EBITDA 指引至少 4,000 万，即至少 -22%。
一句话：静态财务优秀 ≠ 动能优秀。市场正在给 OCL 的未来定价，而不是它的过去。

综合诊断：Objective 是一家商业模式极其干净的 GovTech/RegTech 订阅软件公司——100% 软件收入、86% 经常性收入、94.3% 毛利率、27.6% 净利率、34.5% ROE、零有息负债、净现金 8,307 万。但 FY2026 发生了两件性质严重的事：与国防数字集团（DDG）长达 26 年的国防部合作关系突然中止（对 FY26 营收与盈利无影响，但导致 ARR 未达公司自设目标），以及另一份长期定制服务合同终止。CEO 在年度股东信中直言「在 FY2026 我们远未达到自己的业绩预期」。结果是 ARR 转负、FY27 利润指引大幅下调。

核心优势：① ROE 34.5%，靠 27.6% 净利率而非杠杆驱动（权益乘数仅 1.80）；② 毛利率 94.3%、经常性收入占客户总收入 86%、100% 订阅，收入可预测性极高；③ CFO 4,930 万、FCF 持续为正、零有息负债、净现金 8,307 万，资产负债表极干净；④ 净现金 + 连续 7 年提高分红（FY26 分红 26.0 澳分，+18%，股息率 4.49%）+ FY26 首次回购 710 万，股东回报诚意明确。

核心风险：① 国防部 DDG 26 年合作关系终止——ARR 未达自设目标，客户集中度风险的直接证据（单一大客户即可改变公司方向）；② ARR 转负 -2%（调整后 -5%），其中占 ARR 69% 的 Information Intelligence -5%，且流动递延收入同比 -14.0%，前瞻指标同步转弱；③ FY27 Adjusted EBITDA 指引至少 -22%——本报告 91 分所依据的高 ROE / 高增长不可直接外推；④ 🟡 派息率已从 59.1% 升至 67%，若 FY27 盈利按指引下滑，「连续第 7 年提高分红」的记录面临中断压力；⑤ 🟡 规模天花板——营收仅 1.35 亿、市值 5.54 亿，澳洲 Build 市场仅 North Sydney 一个客户，维州/昆州/西澳仍在开发，投入期长。

4.4 估值总结

估值判断：偏低但需附条件，不能简单按「深度低估」处理。

支持低估的三条硬证据：① PE 14.9x 为财年末序列最低，显著低于 ROE 34.5% 对应的 20–30x 合理区间；② PS 4.11x、EV/Adjusted EBITDA 9.1x，对一家毛利率 94.3%、净利率 27.6%、零有息负债的软件公司属于折价定价；③ 股息率 4.49% + FY26 首次回购 710 万 + 净现金占市值 15%，下行有实质保护。

必须同时承认的三条反证：① 前瞻 PE 已回到 20.30x = 合理区间下沿，「便宜」的窗口主要在静态 EPS 上；② PEG 3.0，低 PE 不是成长换来的，是动能换来的打折；③ 价值陷阱的「增长失速端」已部分命中——ARR -2%（调整后 -5%）、FY27 EBITDA 指引至少 -22%，且与同行的巨大估值差（对比 TNE：ROE 相近但 PE 71.3x、PS 15.8x）说明市场给 OCL 的折价是对增长失速与规模天花板的定价，而不是对财务质量的否定。

操作含义：当前价属于「好公司 + 等待验证的价格」，不是「无脑抄底」。它便宜的前提是 FY27 末期 ARR 止跌回升；若 FY27 中报 ARR 继续负增长，20x 前瞻 PE 会被动下修至 15x 附近（对应约 4.3 澳元，接近 52 周低点）。反之，若 RegWorks V8 + 澳洲 Build + USP uplift 三件事在 FY27 兑现、ARR 回到正增长，则 25x 中枢（动态口径 7.20 澳元 / 静态口径 9.73 澳元）是合理目标区，7 家券商一致目标价 8.77 澳元（+51.5%）位于两者之间、偏乐观端。

5.5 核心结论

变量 3：澳洲 Build 市场 + RegWorks V8 交付节奏

7.4 前景展望

a. 未来 1–3 年核心驱动

正向驱动：
1. RegWorks V8 的 FY27 渐进交付 — 5 年积累的集大成产品，融合 Agentic AI，定位 "regulator-in-a-box"；已被联邦 DCCEEW 选为覆盖其 18 个机构的首选平台，是唯一 ARR 正增长的板块（+4%），交付节奏直接决定 FY27 增量。
2. USP uplift 变现 — UPS（美国养老金监管机构）案例已验证 uplift 系数 1.5x~2.5x，且 FY27 还有 2,400 万澳元的 USP 收入可转化为 uplift 案例；政府合同涨价机制是 SaaS 涨价能力的实证，金额明确、非概念。
3. Planning & Building 的转化队列 — 新西兰 43 个 BCA 正在迁移至 Build 平台（迁移完成后集中体现为 ARR）、35 个客户已覆盖新西兰过半 BCAs、Isoplan 覆盖新大西定东南部绝大多数市议会；该线 SaaS 收入已 +38%，转化只是时间问题。
4. 净现金 + 回购 + 分红的下行保护 — 净现金 8,307 万（占市值 15%）、FY26 首次回购 710 万、董事会将在静默期后（一个月内）复核回购计划、股息率 4.49%，为估值提供实质底部支撑。

负向拖累：
1. ARR 转负的滞后效应 — ARR 1.173 亿（-2%，调整后 -5%）+ 流动递延收入 -14.0%，两项前瞻指标同步转弱，会在 FY27 逐步传导为收入增速放缓，FY28 可能进一步承压。
2. DDG 流失的续费基数效应 — 26 年合作终止意味着这块 ARR 基数永久消失，且需在其他客户身上补回；占 ARR 69% 的 Information Intelligence ARR -5% 说明替代尚未开始。
3. 澳洲市场开拓的投入期 — Build 仅落地 1 个客户，维州/昆州/西澳仍在开发，政府销售周期长；在 NZ 高光的同时澳洲尚未接棒。
4. FY27 折旧摊销继续上行 — 无形资产从 2,681 万增至 3,956 万，摊销已 +20.1%，FY27 将进一步压制净利率（有效税率同时从 14.3% 升至 16.3%）。
5. 规模天花板与竞争 — 营收 1.35 亿、市值 5.54 亿，客户集中于政府机构，竞品包含 Guidewire、Salesforce、DXC、Opus 等全球巨头；一旦 ARR 不再增长，估值将难以维持成长溢价。
