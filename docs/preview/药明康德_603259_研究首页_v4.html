02
Investment Thesis

核心逻辑：三件事同时成立。

增长有订单支撑、盈利有结构支撑、估值有业绩支撑；三者共振，才构成 Buy，而不是单看低 PE。

03
Valuation

估值：便宜，但不是无条件的便宜。

PE 端已进入历史偏低区，PB 端仍在近三年约 80% 分位；低估值的一半是业绩，另一半是地缘折价。

便宜吗？
PE(TTM) 16.38x、PE(2026E) 17.7x，低于 ROE 约 30% 对应的 20–30x 合理区间；近 5 年 PE 分位约 18%。
为什么便宜？
美国收入占比约 77.1%，是唯一被美国国防部列入 1260H 名单的中国 CXO；BCC 清单落地前，估值折价难以完全修复。
有陷阱吗？
PB 4.45x 仍处近 3 年约 80% 分位。PB/PE = ROE，若 ROE 因净资产膨胀或增速回落而均值回归，PB 与 PE 可能同时收缩。

04
Key Risk

最大风险：不是估值，是地缘。

基本面风险可控，真正的尾部风险是一个日期明确的二元事件：OMB 的 BCC 清单。

1260H / BCC 清单 双向 · 高

初步禁令只是冻结执行，不是终局。

2026-08-07 的初步禁令并非永久移出清单；OMB 预计 2026 年底发布 BCC 清单。公司美国收入占比约 77.1%，一旦列入，收入敞口与估值折价会同步放大。这是当前评级最需要主动披露的尾部风险。

另外三个需要盯住的瑕疵

05
What Changes The Call

接下来，只看三个节点。

评级不是一劳永逸。未来两个季度，三个可观测事件足以决定 Buy 是维持、升档还是下调。

2026 年底

OMB 发布 BCC 清单

未列入：估值折价修复，维持 Buy；列入：下调至 Neutral / Underperform。

2027-03

2026 年报 / Q4 收入

全年 610–619 亿元；≥619 亿元且 TIDES Q4 ≥50 亿元 → 升 S；<610 亿元 → 降 B/C。

2027 Q1

TIDES 淡季 / 新基地爬坡

毛利率 ≥54%、在手订单增速 ≥20% → 维持 A；毛利率跌破 50% → 下调至 Neutral。

升档 / 维持 Buy
  • 升 S：Q4 收入 ≥619 亿元 + BCC 未列入 + TIDES Q4 ≥50 亿元。
  • 维持：Q4 收入 ≥610 亿元 + BCC 未列入 + CFO/扣非 ≥1.0。
下调条件
  • Q4 收入 <610 亿元，或 2027 年指引 <700 亿元 → Outperform。
  • BCC 列入，或美国客户收入同比下滑 >10% → Neutral / Underperform。
  • CFO/扣非连续两季 <0.85，或应收增速高于营收 10pct → Outperform。
  • 毛利率跌破 50% → Neutral。
