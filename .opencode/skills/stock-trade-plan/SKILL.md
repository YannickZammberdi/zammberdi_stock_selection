# 个股交易计划模板

## 用途

为一只**基本面已过关**的个股（建议只对持仓中前20%的精选标的使用）生成L11-L13交易计划。输入股票代码，输出一张A4纸篇幅的HTML交易计划书。

**注意：本 skill 不是"默认买入"。先做下方「买入前置判断」，若闸门未通过，输出的是"不建议买入"版本，而不是买入计划。**

## 参考框架

L11-L13 框架定义在 `stock-learning/materials/`，生成前必须通读对应文件：

| 模块 | 框架文件 |
|------|---------|
| L11 估值执行 | `stock-learning/materials/L11-valuation-execution.md` |
| L12 仓位分批 | `stock-learning/materials/L12-position-batch.md` |
| L13 止盈止损 | `stock-learning/materials/L13-stop-profit-loss.md` |

## 读取已有分析报告

生成交易计划前，必须读取该股已生成的 L1-L5 分析报告作为数据基础：

```
stock-learning/stocks-analysis/{市场}/{L5分类}/{股票简称}_{股票代码}_分析报告.html
```

> 查找规则：先在 `stock-learning/stocks-analysis/{市场}/` 下按代码搜索（如 `002001`），再按简称搜索。找到后读取其中的 L1-L4 财务数据、L5 分类结论、L3 估值结论，交易计划中的估值/合理PE目标必须与之一致。找不到分析报告时，先提示用户生成报告，或标注"数据待补充"。

## 报告结构

单页，无tab，全部展开显示。包含以下模块：

### 1. 头部信息
- 股票名称代码、日期（YYYY-MM-DD格式，精确到日）、L5分类
- 当前状态标签（计划中/持有中/已结束）

### 2. 估值概览（L11）
- 赚什么钱（估值修复/业绩增长/股息）
- 当前PE分位、PB分位、ROE
- 合理PE目标
- PE分位进度条

### 3. 估值目标
- 现价、EPS(TTM)
- PE修复到不同目标的空间（%）
- 时间预期

### 4. 买入检查清单（正反两面）
- 左列：利好因素（绿色，打勾）
- 右列：风险因素（红色，感叹号）
- 底部：综合判断 + 建议

### 5. 仓位计划（L12）
- 总计划仓位 / 已买 / 剩余
- 分批建仓明细（第一批/第二批/第三批的价格和条件）

### 6. 止损规则（L13）
- 硬止损价和幅度（%）
- 基本面止损条件列表

### 7. 止盈规则（L13）
- 各批次止盈触发条件（PE目标价或股价）
- 移动止盈规则

### 8. 跟踪指标
- 每行一个指标：名称 + 用途说明 + 当前值 + 信号（红/绿/黄）

### 9. 持有期限
- 最短持有时间 + 最长持有时间
- 三种情景：估值先到 / 业绩兑现 / 逻辑证伪

### 10. 催化剂
- 左列：利好催化剂
- 右列：利空风险

## 数据来源

**获取顺序（优先级从高到低）：**
1. **已生成 L1-L5 分析报告** — 财务数据、L5分类、估值结论优先读取该报告
2. **websearch 实时搜索** — 最新股价/PE/PB及历史分位，优先用 `websearch` 获取，记录来源和日期
3. **用户提供** — 用户消息中给出的当前估值数据、个人仓位上限偏好
4. **知识内已知数据** — 仅用于无法搜索到的历史参考值，必须标注"历史参考"

数据项及来源：
- 股价/PE/PB：websearch 实时行情（东方财富、亿牛网等）
- PE/PB历史分位：websearch（亿牛网分位数据）
- 产品价格（视具体标的不同）：websearch（券商研报、百川盈孚等行业网站）
- 财报数据：已生成的L1-L5分析报告

**数据缺失处理：** 某项数据搜索不到且用户未提供时，对应单元格标注"数据待补充"（灰色），**不要编造数据**。仓位/止损/止盈价格必须有明确依据，无依据时用"待定"。

## 使用条件

该技能**仅用于已经通过L1-L5基本面分析、值得进一步考虑的标的**。不适用于：
- 纯概念炒作股
- 尚未盈利的成长初期公司
- 已触发卖出信号的持仓

## 买入前置判断（可以输出"不建议买入"）

写交易计划**之前**先做闸门检查：读 L1-L5 报告 + websearch 最新估值后，命中以下任一条件 → **不写买入计划**，改为输出"不建议买入"版本：

1. **估值无安全边际**：现价 ≥ 合理PE目标价，或 PE/PB 分位 > 70%
2. **基本面不达标**：L5 评分 < 60，或 L2 排雷发现硬伤（高质押/大额商誉/现金流背离/造假嫌疑）
3. **逻辑证伪迹象**：L1-L4 核心增长逻辑出现证伪（客户流失/技术路线失效/政策转向）
4. **已触发卖出信号**（持仓）：已触发 L13 止损或基本面止损，或 C方案 验证为"言行不一致"
5. **你自己不懂这生意**：无法用三句话讲清它的护城河和赚钱方式（请用户确认）

**"不建议买入"版本的输出规范**（同一套 HTML 模板、同一配色，但内容替换）：
- 头部状态标签改为红色 `不建议买入`
- 顶部结论区：三句话——为什么曾进入观察 / 为什么现在不买 / 什么条件下才重新看
- 放弃理由清单：每条必须带数据依据（现价、PE分位、ROE、触发指标等），不空泛
- 重新关注触发条件：给出具体的价格/估值分位/基本面事件阈值，达到后再重新跑 L1-L13
- **明确不写**：买入批次、仓位、止损止盈数字——避免"看了计划就想买"
- 布局与正常交易计划一致，只是把"仓位计划/止损/止盈"三节替换为"放弃理由/重新关注条件"两节

若所有闸门通过 → 正常输出买入交易计划。

## 执行与更新

交易计划写好后，持有期间应持续执行并更新：
- 每次触及止盈/止损/分批买入后，更新对应状态标签（计划中→持有中→已结束）和剩余仓位
- 计划更新时保留历史记录，追加一条"执行记录"，不覆盖原计划数字
- 更新后重新执行下方 QC 检查

## 生成后检查（QC）

生成完成后逐项核对：
- [ ] 头部日期为 `YYYY-MM-DD` 格式，状态标签与当前状态一致（计划中/持有中/已结束/不建议买入）
- [ ] 先做了「买入前置判断」：若命中任一闸门条件，输出的是"不建议买入"版本（含放弃理由+重新关注条件），而非买入计划
- [ ] "不建议买入"版本未出现买入批次/仓位/止损止盈数字
- [ ] 估值数据（现价/PE/PB分位）与 L1-L5 分析报告或 websearch 来源一致
- [ ] 合理PE目标与L3估值结论一致，PE分位进度条数值与当前分位一致
- [ ] 买入检查清单正反两面各≥2条，底部有综合判断
- [ ] 仓位计划：总仓位=已买+剩余，分批价格/条件具体可执行
- [ ] 止损/止盈规则有明确触发价（数值或计算方式），非空泛描述
- [ ] 跟踪指标每行含信号（红/绿/黄）
- [ ] 数据待补充项有明确标注，未影响核心仓位/止损决策

## 用户角色

- 用户负责提供：股票代码 + 当前估值数据 + 个人仓位上限偏好
- 模型负责：生成完整HTML交易计划书

## 样式规范

CSS全部内联在HTML中，无需外部依赖。配色沿用已有的`col-tag`体系（绿/红/黄/蓝），新增：
- `bar` 进度条（PE分位可视化）
- `check` 检查清单（圆点+打勾/感叹号）
- `grid-3` 三列仓位/止损/止盈卡片

参考现有 `stock-learning/stocks-analysis/交易计划/新和成_002001_交易计划.html` 的全部样式和结构，生成时替换数据和内容即可。
